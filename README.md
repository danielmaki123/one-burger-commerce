# One Burger Commerce

MVP para pedidos de One Burger basado en el proyecto auditado de Casa Antigua, reducido a menu, carrito, checkout para retirar, ordenes admin, menu admin y usuarios admin.

## Stack

- Next.js App Router
- TypeScript
- Prisma
- Vitest
- ESLint

## Alcance MVP

- Publico: home, menu, detalle de producto, carrito y checkout pickup.
- Admin: ordenes, menu y usuarios.
- Roles: `owner`, `manager`, `kitchen`.

Fuera del MVP: reservas, mesas, delivery, inventario, reportes avanzados y pagos online.
